## 三级跳转的实现差异（记下来免得以后混）

| 插件 | 搜索结果 id 是什么 | 跳转要做什么 |
|---|---|---|
| 计划 | 计划 id | 直接 `openPlan()` 进详情 |
| 备忘 | 备忘 id | 滚到那条 + 闪（没有详情页） |
| 清单 | **条目** id | 先查条目属于哪个清单 → 打开那个清单 → 滚到条目 + 闪 |
| 日记 | 日记 id | 滚到那篇 + 闪 |

清单这条是唯一需要二次查询的：搜索结果只有条目，清单名在副标题里给用户看，
但打开要的是 listId。
