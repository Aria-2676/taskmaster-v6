# 规则卡 · 文档维护

> 最后更新：2026-11-01
> 适用：新增、修改、拆分、归档 `docs/` 下的文档。

## 必须

- 新文档先定唯一源：规则 → `conventions/`；取舍 → `decisions.md`；计划 → `ROADMAP.md`；
  AI 流程 → `ai/`；验收 → `acceptance/`。
- 改完更新 `docs/INDEX.md` 的文件分工表；否则等于没写。
- 标题下加 `> 最后更新：YYYY-MM-DD`；不回填旧文档。
- 被证伪的断言删掉，在 INDEX“已证伪”表留一行“曾这么写过、为什么错”。
- 描述的东西已结束 → 移入 `docs/archive/`；还在改 → 留 `docs/` 根。
- 常读文档单篇约 200 行上限；超了拆开或移入归档。
- 文件名 ASCII；内容可中文。

## 禁止

- 在 `.trae/`、`CLAUDE.md`、`.workbuddy/`、README 里复制规则全文。
- 归档区内容再修改（历史只增不改）。
- 保留“已证伪但留作参考”的断言。
- 写无法判定的词（“正常”“大概”“以后再说”）。
- 写没跑过的命令/路径/版本号。

## 判据

| 问题 | 判据 |
|---|---|
| 该归档吗？ | 描述的功能/版本/一次交付已经结束 |
| 该拆吗？ | 常读文档超过约 200 行 |
| 该放哪？ | 见 `docs/INDEX.md` 文件分工表 |
| 是不是重复规则？ | 同一句话是否已在 `docs/conventions/` |
