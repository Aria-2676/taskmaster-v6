# 验收清单：首页模式插件化 + 第一个模式插件「计划模式」

> 最后更新：2026-10-31

本轮做了三件事：
1. 契约里加 `home` 声明（**不是准入**，只决定默认开不开 + 模式叫什么名字）；
2. 快捷切换的存法从"收起集合"改成"默认值 + 只记偏离默认的覆盖"，带 6.0.4 数据迁移；
3. 新插件 `plan_mode`（周计划 → 模式名「计划模式」）。

**没上真机**，只在 `flutter test` 里跑过（562 通过）。手感项（B3 底部动作层的
高度、B4 挪动后的滚动位置）必须真机看。

前置：插件市场里能装到「周计划」（随包资产，断网也能装）。

## A. 模式声明与默认值

| # | 路径 | 操作 | 可观察预期 | 不过时先看 |
|---|---|---|---|---|
| A1 | 侧边栏 → 首页模式 | 装了「周计划」之后打开 | 出现「**计划模式**」，副标题是「未来七天铺开，点任务改期」（不是「插件整页 · v1.0.0」），右侧开关**默认开** | `buildModeOptions` 里 `home?.label ?? nameOf` |
| A2 | 同上 | 看「周计划」以外的插件行 | 开关**默认关**，但可以打开 —— 没有"不能当首页"的说法 | `defaultQuick: home != null` |
| A3 | 首页 → 顶栏箭头 | 点开 | 只列出计划模式 + 任务模式；把某个未声明的插件打开后，它才会出现在这里 | `quickOptions` 的 `visibleOf` |
| A4 | 同上状态 | 杀掉 App 重开 | 刚才的开关状态还在 | `ui.home_quick_overrides` |
| A5 | 首页模式页 | 看「任务模式」与当前模式那行 | 两个开关都是灰的、点不动、恒开 | `_quickSwitch` 的 `locked` |
| A6 | 升级路径 | 在 6.0.4 里先关掉某个插件的快捷项 → 升到本版 | 它**仍然关着**（迁移把旧的收起集合转成了"显式关闭"） | `HomeModeStore.load` 的 legacy 分支 |
| A7 | 首页模式页 | 把某个模式关掉再打开，然后看数据库 `ui.home_quick_overrides` | 关→开回到默认值后，这一项**从记录里消失**（不是记成 `+`） | `setQuickVisible` 里 `visible != defaultOn` |

## B. 计划模式

| # | 路径 | 操作 | 可观察预期 | 不过时先看 |
|---|---|---|---|---|
| B1 | 首页模式 → 选「计划模式」 | 回首页 | 顶栏标题变成「**计划模式**」，右侧箭头在；底栏**没有** `+` | `_headerTitle` / `_modeAllowsAdd` |
| B2 | 计划模式页 | 看列表 | 未来 7 天，今天在最上面并高亮；每天一个计数；没任务的天写「这天是空的」 | `plan_mode/index.html` 的 `render()` |
| B3 | 计划模式页 | 点任意一条任务 | 底部升起动作层：标题是任务名，下面是 7 个日期按钮（当前那天描边），底部「标记完成 / 取消」 | `openSheet()` |
| B4 | 动作层 | 选另一天 | 动作层关闭，任务从原处消失、出现在目标日，顶部提示「挪到明天」之类 | `move()` + `task.update` |
| B5 | 动作层 | 点「标记完成」 | 标题划掉置灰，顶部的「x/y 已完成」跟着变；再点一次可取消 | `task.setDone` |
| B6 | 计划模式页 | 杀掉 App 重开 | 数据和刚才一致（没有插件自己的表，全部来自主包） | `plan_mode/plugin.json` 无 `storage` |
| B7 | 切回任务模式 | 看原来那天 | B4 挪过去的任务在它该在的那天 —— 两处是同一份数据 | 同上 |
| B8 | 计划模式页 | 手指滑动列表 | 滚动正常，**不会**因为点按而误触发改期（改期必须点开动作层） | 只有 `click` 监听，没有拖拽 |
