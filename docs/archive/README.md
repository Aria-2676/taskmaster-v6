# 归档区

只读记录，不参与开发。**新内容不往这里写**，只在"这件事已经结束"时移进来。

## 分类

| 子目录 | 放什么 | 什么时候会有用 |
|---|---|---|
| `design/` | 已实现的设计文档。代码是权威，这里留的是"当时为什么这么设计" | 想改这块功能，但先看当初的取舍 |
| `acceptance/` | 已签收的验收清单 | 追溯"某次交付到底验了什么" |
| `handoff/` | 过期的一次性交接说明 | 想接上一段中断的工作 |

## 两条规则

1. **进了这里就不再改**。要改功能，去改 `docs/` 里的活文档或代码。
2. **文内提到的路径是写作当时的**。比如 `docs/acceptance/xxx.md` 现在已经在本目录下，
   按原路径找会扑空 —— 直接在本目录按文件名搜。
