# 2026-11-01 番茄钟（主包计时 + 到点通知）+ 清单模式新建

- **任务 id**：pomodoro-6.1.0
- **协调者**：用户

- **状态**：`in_progress`

## 范围

要做：

1. **主包计时引擎**（纯 Dart，可测）：专注 25 / 短休 5 / 长休 15，每 4 个专注一长休；
   开始 / 暂停 / 继续 / 重置；暂停不计入有效时长。
2. **到点通知**：开始或继续时排一个精确闹钟；暂停 / 重置时取消；进程被杀后重开，
   通知仍按原计划触发（`zonedSchedule` 走 AlarmManager，不需要前台服务）。
3. **状态持久化与恢复**：`settings` 里一条 JSON 存"正在计时"的会话；冷启动按
   `startedAt + 有效时长` 重算剩余；已过期则立即结算并派发事件。
4. **`pomodoro.sessionFinished` 接通**：`HookId` 里已有这个枚举，但没有派发点。
5. **通知能力开放给插件**：bridge 新增 `notify.show` / `notify.cancel`（additive，
   **不动 contract 版本**，老插件不读它照旧工作）。
6. **清单模式加"新建"**：输入标题 + 选截止日期，走已有 `task.create`；
   不新增 bridge 能力。

明确不做：

- **前台服务 / 常驻通知**（用精确闹钟 + 启动恢复替代，理由见 decisions）。
- 桌面小组件、统计页面、云同步。
- 番茄钟插件自己的 UI 今晚不做完：先把主包侧跑通（ROADMAP §9「先做最小闭环」）。

## 验收口径

分两层（见 `docs/conventions/acceptance-template.md`）：

- **机器判**：状态机（暂停不计、到点标记、跨阶段）、持久化恢复（构造过期/未过期两种状态）、
  权限拒绝时不静默 —— 全部写成测试。
- **人判（模拟器）**：25 分钟专注退到桌面仍走完并弹通知；杀进程重开通知仍按计划到；
  清单模式新建能选日期并落到那天。
