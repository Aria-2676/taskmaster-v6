# 交接模板

> 最后更新：2026-11-01

> 用在任务文件的“交接区”，或单独写给下一个 agent/人。不要只留在聊天里。

```markdown
# 交接 · <任务/主题>

> 时间：<YYYY-MM-DD HH:mm> ｜ 当前状态：<一句话>

## 当前状态

- 正在做什么：<具体到文件/函数/页面>
- 已经能跑通的部分：<命令/测试/真机步骤>
- 还不能跑通的部分：<现象/报错原文>

## 已完成

- <改动 1>（文件/测试）
- <改动 2>（文件/测试）

## 下一步（按顺序）

1. <具体动作：改哪个文件、跑哪个命令>
2. <验证方式>
3. <需要的裁决/用户输入>

## 已知坑 / 失败尝试

- <试过 X，结果 Y，不要再试>
- <环境限制：代理/设备/路径>

## 未验证

- <真机手感/边界/未复现 bug/跳过的平台>

## 文件与提交

- 分支/提交：<sha 或“未提交”>
- 关键文件：<路径>
```

## 写法要求

- “下一步”必须具体到文件和命令，不要写“继续完善”。
- 失败尝试要写结果，避免下一个人重试同一个方向。
- 未验证项必须诚实列出；不要把“测试全过”当成全部已验证。
