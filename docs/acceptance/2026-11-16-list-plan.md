# 验收 · 6.5 清单升级 + 6.6 计划重建（2026-11-16）

> 环境：模拟器（Android 17 / x86_64），v6 主包 + 插件走仓库分发
> 说明：**每一项都是我实际点过、看到结果的**；没跑过的写在最后「未验证」。

## 6.5 清单（list_mode 2.0.x）

| # | 操作 | 预期 | 实测 |
|---|---|---|---|
| 1 | 侧边栏 → 待办清单（空数据） | 显示「还没有清单。新建一个，比如『露营打包』」 | ✅ |
| 2 | 点「新建」→ 输入名字 → 确定 | 弹出**页面内**输入框（不是 Android 灰框），创建后自动进入内页 | ✅ |
| 3 | 内页输入 3 条（Tent / SleepingBag / Stove） | 三条都出现，进度「0 / 3」 | ✅ |
| 4 | 点第一条前的方框 | 变紫勾 + 删除线，进度「1 / 3」，清空已完成按钮启用 | ✅ |
| 5 | 点第二条的「转任务」 | 该条变完成（2/3），toast 提示；**首页任务列表出现同名任务** | ✅ |
| 6 | 杀掉 App 重开 → 再进清单 | Camping 清单和 3 条条目都在 | ✅ |
| 7 | 底部「存为模板」→ 确认名字 | 回清单库，出现「模板」分区 + 模板徽章 + 「用这个新建」 | ✅ |
| 8 | 点模板的「用这个新建」→ 确认 | 新清单「Camping 11/15」，3 条条目复制过来，全部未完成（0/3） | ✅ |

## 6.6 计划（plan_mode 2.0.x）

| # | 操作 | 预期 | 实测 |
|---|---|---|---|
| 1 | 侧边栏 → 计划（空数据） | 显示「还没有计划。新建一个，比如『三个月读完 12 本书』」 | ✅ |
| 2 | 点「新建」→ 名字 ReadBooks → 创建 | 卡片出现：名字、日期范围 2026-11-15 ~ 2026-12-15、进行中、空进度条 | ✅ |
| 3 | 点卡片进详情 | 四个分区：阶段 / 里程碑 / 任务 + 删除计划 | ✅ |
| 4 | 「+ 加阶段」→ Phase1 | 阶段出现，进度「0 / 1 项」 | ✅ |
| 5 | 勾选 Phase1 | 进度条满、100%、「1 / 1 项」 | ✅ |
| 6 | 「+ 加里程碑」→ Milestone1（日期默认今天） | 里程碑出现（名字 + 2026-11-15），进度「50% · 1 / 2 项」 | ✅ |
| 7 | 主包建任务 PlanTask → 回来「+ 排入任务」→ 勾选 → 加入 | 任务出现在计划里，进度「33% · 1 / 3 项」，带「改期 / 移除」 | ✅ |
| 8 | 今日页「计划」块 | 显示「🏳 ReadBooks　33% · 到 2026-12-15」 | ✅ |

## 未验证（如实记录）

- **中文输入**：模拟器只能 `adb input text` 打 ASCII，名字都用的英文。中文名字的实际显示/输入没验。
- **长列表**：清单条目 > 20 条、计划阶段 > 10 个的滚动与性能没压过。
- **改期**：弹层能打开、点确定不报错，但**没能确认任务日期真的变了**（任务本来就在今天，改成同一天看不出差异）。
- **`where` 传整数 0 查不到**：计划插件用 `where status=0` 查进行中计划恒为空，改前端过滤才通。宿主 `select` 的单测里同样条件能查到（已补测试锁住），
  所以不是 `_where`/`_valuesParam` 的显式 bug，具体成因未定位。清单的 `list.pending` 也已改成前端过滤规避。
