# 决策记录模板

> 最后更新：2026-11-01

> 追加到 `docs/decisions.md`，不要单独新建文件。只记“为什么”，不抄规则。

```markdown
## <决策标题>（<YYYY-MM-DD>）

### 背景

- 现在的事实/问题：<代码/数据/用户反馈>
- 触发点：<哪件事让这个问题必须现在定>

### 决策

- 采用：<一句话>
- 代价：<明确写出来>
- 放弃的选项：<A/B/C，各自为什么不选>

### 影响

- 代码：<文件/模块>
- 数据/契约：<表/字段/bridge/插件版本>
- 文档：<需要同步的文件>
- 发布：<是否需要发版/插件重打>

### 验证

- 怎么证明它生效：<测试/命令/真机步骤>
- 怎么证明它没坏：<回归项/反向测试>
```

## 要求

- 一条决策只回答一个问题；不要把多个取舍混在一起。
- 被推翻的旧决策不要删，标注“已作废/更正”并写原因。
- 如果影响插件可见接口，写清契约版本是否 +1。
