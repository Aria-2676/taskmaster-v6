# 2026-11-17 诊断能力验收

## 背景

2026-11-16 排查插件问题，所有现场只剩用户一句"点了没反应" ——
JS 报错、离屏查询返 unsupported、插件加载失败，全沉在 logcat 里，
手机上完全看不见。这轮补两件事：日志能看、插件现场能贴出来。
