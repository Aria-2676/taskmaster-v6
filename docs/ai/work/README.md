# 正在进行的任务

> 最后更新：2026-11-01

每个非平凡任务一个文件：`<YYYY-MM-DD>-<英文短名>.md`，从
`docs/ai/templates/task-claim.md` 复制。

## 规则

- **开工前先建文件**；同一主题只允许一个 owner。
- 只改自己的任务文件；不要编辑别人的 claim。需要协调时在对话里说明，由协调者改。
- 状态用 `claimed / in_progress / blocked / review / done`。
- 任务结束后文件保留，不删；它记录“当时怎么做的”。
- 真人小改动（文案/单文件 UI/注释）可跳过任务文件，但仍要走交付纪律。

## 命名

- 英文短名，ASCII，2–6 个词，例如 `2026-11-01-pomodoro-timer.md`。
- 不用中文文件名（API 推送会失败）。

## 查找

- 用 `Glob docs/ai/work/*.md` 看当前任务；按日期/主题排序。
- 接手前先读任务文件的“交接区”，不要凭聊天记忆继续。
