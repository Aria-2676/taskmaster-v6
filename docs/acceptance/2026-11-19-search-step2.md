## 期间修掉的一个真 bug

**离屏查询的 registry 登记会被前台插件页的 `unregister` 一起删掉。**

机制：
1. 打开计划插件 → `PluginView` 把 `query` 登记到 registry（前台页面回答查询）
2. 关闭插件页 → `dispose` 调 `PluginQueryRegistry.unregister(pluginId)` —— 它按 id 删，
   **离屏那份登记跟着一起没了**
3. 再搜索 → `acquire` 命中"实例还在、路径没变"，直接返回 `true` 并复用，
   **不会重新登记**
4. `query` 查不到 handler → 返回 `unavailable` → 界面显示「有模式没连上，可能漏了结果」

修复：`acquire` 的复用分支在返回前重新 `register`。这样无论谁把登记删了，
下一次问之前都会补回来。**这是"复用前先自检"，不是"猜谁删的"** ——
`unregister(pluginId)` 按 id 删的语义不改（改它要动注册表的所有调用方）。

现象是"搜索一直说没连上、但插件明明装着、打开它也是好的"，很容易误以为是插件没实现。
